# CalcConvert

A beginner-friendly, menu-driven **Command-Line Interface (CLI)** application in Python 3 that performs:
- Basic arithmetic (add, subtract, multiply, divide, modulus, exponentiation)
- Currency conversion (example rates)
- Unit conversion (length, weight, temperature, time)

---

## Requirements

- Python **3.8+** (no external libraries needed)

---

## Setup

```bash
# Clone or download the project
cd calcconvert

# Run it
python main.py
